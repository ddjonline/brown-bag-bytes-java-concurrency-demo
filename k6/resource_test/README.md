# k6-proxy-test

## Prerequists

Download and save [K6](https://k6.io/) to a location on the development machine (ex: C:\tools\k6-v0.58.0-windows-amd64) and either add to the PATH or just use the path to the `.exe` as in the examples below.

## Run the test

```shell
/c/tools/k6-v1.3.0-windows-amd64/k6.exe run main.js
```
